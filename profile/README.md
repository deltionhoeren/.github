# Deltion hoeren

Welkom op de GitHub-organisatie van **Deltion hoeren**.

Deze organisatie gebruiken we om onze projecten, opdrachten en experimenten centraal te beheren. Hier werken we samen aan software, websites en andere ICT-projecten.

## Wat vind je hier?

* Projecten en schoolopdrachten
* Websites en applicaties
* Experimentele projecten
* Code, documentatie en configuratie
* Samenwerkingen tussen teamleden

## Samenwerken

We proberen onze repositories overzichtelijk en makkelijk te begrijpen te houden.

Bijdragen kan bijvoorbeeld via:

1. Maak een issue aan voor een bug, idee of verbetering.
2. Maak een branch voor je wijziging.
3. Open een pull request met een duidelijke beschrijving.
4. Verwerk feedback voordat de wijziging wordt gemerged.

## Technologie

De gebruikte technologie verschilt per project. Denk bijvoorbeeld aan:

* HTML / CSS / JavaScript
* TypeScript
* PHP
* Python
* Git & GitHub

De specifieke technologieën en instructies staan in de README van de betreffende repository.
